# TadbirkorAI

O‘zbekiston tadbirkorlari uchun AI moliyaviy va biznes yordamchi.

**Asosiy qiymat:** to‘g‘ri kreditni topish → nima uchun mos → mablag‘ni rejalashtirish → biznes natijasi.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzer: http://localhost:3000

## Ekranlar

- Bosh sahifa
- AI maslahatchi
- Kredit topish / taqqoslash / taqsimot / roadmap
- Biznes reja
- Tahlil
- Vazifalar
- Profil

Barcha interfeys matnlari o‘zbek lotinida. Demo ma’lumotlar — namuna.
